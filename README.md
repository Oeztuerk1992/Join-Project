# Join 360 – Kanban Project Management Tool

A collaborative web application for managing tasks and projects using a Kanban board. Built as a student group project.

---

## Features

- **Dashboard (Summary)** – Key metrics at a glance: open tasks, urgent items, deadlines
- **Board** – Drag-and-drop Kanban board with task columns
- **Add Task** – Create new tasks with title, description, due date, priority and assignees
- **Contacts** – Manage team members with a searchable contact list and detail view
- **Responsive Design** – Optimized for desktop and mobile

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Firebase (Backend & Authentication)

---

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Oeztuerk1992/join.git
   ```
2. Open the project folder in VS Code
3. Start with Live Server from the project root (`Join Projekt/`)
4. Open `index.html`
